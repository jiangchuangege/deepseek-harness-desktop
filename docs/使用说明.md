# 使用说明

## 一、安装

**普通用户**:从 [Release v1.1.0](https://github.com/jiangchuangege/deepseek-harness-desktop/releases/tag/v1.1.0) 下载:

- `DeepSeek.Harness.Setup.1.1.0.exe`(安装版,推荐)或 `DeepSeek.Harness.1.1.0.exe`(便携版);
- 无需安装 Node/Python,双击即用。

**开发者/源码方式**:
```bash
npm install      # 首次, 安装依赖(需联网)
npm start        # 启动桌面客户端
```

客户端启动时会:
1. **自动拉起本地工具调用补丁**(`scripts/qwen_tool_proxy.py`, 监听 8081 → 上游 8080);
2. **打开 DSH Web 界面**窗口(默认 `http://127.0.0.1:3080`)。

## 二、环境要求

| 依赖 | 版本 | 用途 |
|------|------|------|
| Node.js | 18+ | 运行 Electron & DSH(仅源码方式需要) |
| Python | 3 | 运行本地工具调用补丁(scripts/qwen_tool_proxy.py) |
| DeepSeek Harness | 最新 | 被客户端包裹/驱动(默认连接 http://127.0.0.1:3080) |

## 三、确认补丁在跑

在浏览器/终端访问 `http://127.0.0.1:8081/v1/models`,能看到模型列表即补丁正常。
客户端里「插件 / 技能 / MCP 市场」窗口(文件菜单 → 社区插件市场, 或 `Ctrl+Shift+P`)右上角有
**补丁在线状态徽标**,绿色=在线并显示模型名,红色=离线。

## 四、启动 / 管理 DeepSeek Harness 服务

DeepSeek Harness 的界面要靠 `dsh web` 这个服务(默认 `http://127.0.0.1:3080`)才能打开。
客户端内置了服务管理,入口有:

- **文件菜单** → `启动 DeepSeek Harness 服务`(`Ctrl+Shift+S`)/ `停止 DeepSeek Harness 服务` / `检查服务状态`;
- **桌面宠物** 点击菜单 → `🚀 启动 DeepSeek Harness 服务`;
- **系统托盘** 右键 → `🚀 启动 DeepSeek Harness 服务` / `检查服务状态`。

点「启动服务」会后台拉起 `dsh web --no-open`,稍候自动加载界面(不会额外弹出浏览器)。
若服务已在运行(或由外部/其它实例托管),会提示"已在运行"并刷新界面;
「停止服务」仅能停止由本客户端自己拉起的 `dsh web` 进程。

## 五、插件 / 技能 / MCP 市场

「插件 / 技能 / MCP 市场」窗口分三个 Tab:

| Tab | 作用 |
|-----|------|
| 插件 / 技能 | 搜索 GitHub 社区仓库(每页 30 条, 可翻页),或从内置精选一键安装(`dsh plugin add`, 带实时进度条) |
| MCP 服务器 | 搜索/精选 MCP 服务器,点【打开 GitHub 仓库】前往仓库查看安装/配置说明;结果可翻页 |
| 管理 | 查看已安装插件(经 `dsh plugin add` 成功安装后自动记录),可**启用 / 停用**、**删除** |

- 已安装插件的启用状态保存在**用户数据目录**(`app.getPath('userData')`),不受便携版临时目录清空影响。
- MCP 服务器**不提供一键部署**:客户端只负责打开其 GitHub 仓库页面,需要你自己按仓库说明运行/接入。

## 六、桌面宠物

- 一个**透明的 Live2D 二次元小角色**(含眨眼/呼吸/点头等动作),不再是贴图;
- 可**拖拽**到屏幕任意位置,位置会被记住,下次启动还原;
- **单击**弹出生动菜单(聊天 / 社区插件市场 / 启动 DeepSeek Harness 服务 / 检查补丁 / 关闭);
- 为省资源,**平时静止,鼠标碰到才动**;
- 如透明悬浮在你的 Windows 上造成明显掉帧,可设环境变量 `PET_TRANSPARENT=0` 关闭透明(改回不透明卡片)。
- **聊天窗口**:本地模型在线时(补丁 8081 + 上游可达)由**本地模型回答**,离线时自动回退到内置规则回复。

## 七、让本地 Qwen 模型可操控电脑

在 DSH 配置(settings)里把该模型的 `baseURL` 指向补丁:
```yaml
llm-pi-ai:
  providers:
    llama:
      baseURL: http://127.0.0.1:8081/v1     # 指向补丁, 而非 llama-server 的 8080
      models:
        - id: <你的模型id>
          contextWindow: <按实际 n_ctx>
```
然后在 DSH 切到该模型并对它说"用工具 xxx",即可验证操控电脑。

## 八、环境变量(可选)

| 变量 | 默认 | 说明 |
|------|------|------|
| `DSH_WEB_URL` | `http://127.0.0.1:3080` | 客户端打开的 DSH Web 地址 |
| `HARNESS_LAUNCH_DSH` | 未设置 | 设为 `1` 时, 客户端自动拉起 `dsh web` |
| `HARNESS_PROXY_UPSTREAM` | `http://127.0.0.1:8080` | 补丁上游地址 |
| `PET_TRANSPARENT` | `1`(透明) | 设为 `0` 关闭宠物透明(Windows 掉帧明显时用) |

## 九、打包成安装程序

```bash
npm run dist
```
在 `release/` 下生成 Windows 便携版与安装包(`.exe`), 需要联网下载 Electron/打包器。

## 十、排障

| 现象 | 处理 |
|------|------|
| 窗口空白 / 打不开 | 确认 DSH 在 3080 已运行; 或设置 `DSH_WEB_URL` 指向实际地址; 也可用「文件菜单 → 启动 DeepSeek Harness 服务」 |
| 本地模型不调用工具 | 确认补丁在 8081 运行; 确认 DSH 里模型 `baseURL=8081` 且已声明 `contextWindow` |
| 宠物透明导致卡顿 | 设 `PET_TRANSPARENT=0` 关闭透明 |
| `npm start` 报错 | 先 `npm install`; 若网络失败, 手动重试或换镜像 |
