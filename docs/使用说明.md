# 使用说明

## 一、环境准备

| 依赖 | 版本 | 用途 |
|------|------|------|
| Node.js | 18+ | 运行 Electron & DSH |
| Python | 3 | 运行工具调用补丁(qwen_tool_proxy.py) |
| DeepSeek Harness | 最新 | 被客户端包裹/驱动(默认连接 http://127.0.0.1:3080) |

## 二、启动

```bash
npm install      # 首次, 安装依赖(需联网)
npm start        # 启动桌面客户端
```
Windows 直接双击 `启动客户端.bat` 亦可。

启动时客户端会:
1. **自动拉起工具调用补丁**(`scripts/qwen_tool_proxy.py`, 监听 8081 → 上游 8080);
2. **打开 DSH Web 界面**窗口(默认 `http://127.0.0.1:3080`)。

## 三、确认补丁在跑

在浏览器/终端访问 `http://127.0.0.1:8081/v1/models`,能看到模型即补丁正常。

## 四、让本地 Qwen 模型可操控电脑

在 DSH 配置(settings)里把该模型的 `baseURL` 指向补丁:
```yaml
llm-pi-ai:
  providers:
    llama:
      baseURL: http://127.0.0.1:8081/v1     # 指向补丁, 而非 llama-server 的 8080
      models:
        - id: <你的模型id>
          contextWindow: <按实际 n_ctx>
```
然后在 DSH 切到该模型并对它说"用工具 xxx",即可验证操控电脑。

## 五、环境变量(可选)

| 变量 | 默认 | 说明 |
|------|------|------|
| `DSH_WEB_URL` | `http://127.0.0.1:3080` | 客户端打开的 DSH Web 地址 |
| `QWEN_LAUNCH_DSH` | 未设置 | 设为 `1` 时, 客户端自动拉起 `dsh web` |
| `QWEN_PROXY_UPSTREAM` | `http://127.0.0.1:8080` | 补丁上游地址 |

## 六、打包成安装程序

```bash
npm run dist
```
在 `release/` 下生成 Windows 安装包(`.exe`), 需要联网下载 Electron/打包器。

## 七、排障

| 现象 | 处理 |
|------|------|
| Window 空白 / 打不开 | 确认 DSH 在 3080 已运行; 或设置 `DSH_WEB_URL` 指向实际地址 |
| 本地模型不调用工具 | 确认补丁在 8081 运行; 确认 DSH 里模型 `baseURL=8081` 且已声明 `contextWindow` |
| `npm start` 报错 | 先 `npm install`; 若网络失败, 手动重试或换镜像 |
