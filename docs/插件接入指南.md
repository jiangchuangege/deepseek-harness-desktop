# 🧩 插件接入指南

本客户端的"插件"统一在 **`config/plugins.json`** 注册,分类为:

| 类别 | 意义 | 示例 |
|------|------|------|
| `patches` | 本地补丁/转换层(如 Qwen 工具调用补丁) | `scripts/qwen_tool_proxy.py` |
| `plugins` | DSH 插件(可来自 GitHub)/ Agent 预设 | `@deepseek-ai/dsh-agent-presets` |
| `skills` | DSH 技能(SKILL 包) | `cordis-plugin-development` |
| `mcpServers` | MCP 服务器(外挂能力) | 读文件/搜网页/操作工具 |

> 🖥️ 客户端入口:「插件 / 技能 / MCP 市场」窗口 —— 文件菜单 → 社区插件市场,或 `Ctrl+Shift+P`。

---

## 一、插件项的结构

```json
{
  "id": "插件唯一id",
  "type": "Plugin | Skill | MCP | Patch",
  "name": "显示名",
  "enabled": true,
  "desc": "一句话说明",
  "source": "来源说明或安装标识"
}
```

---

## 二、如何新增一个插件

### 方式 A:编辑 `config/plugins.json`
把新插件按上面的结构加进对应分类,客户端窗口即可通过 `window.harnessDesktop.getPlugins()` 读到。

### 方式 B:直接装进 DSH(推荐补充第三方插件)
DSH 有插件安装命令:
```bash
dsh plugin --profile web add <包名>
# 例如
dsh plugin --profile web add <GitHub 上的某个 DSH 插件>
```
或一次性批量:
```bash
powershell -ExecutionPolicy Bypass -File scripts\install-plugins.ps1
```
> 会把 `config/plugins.json` 里 `enabled: true` 且 `source` 以 `github.com/` / `https://` / `npm:` 开头的项批量安装。

### 方式 C:客户端窗口内一键安装
在「插件 / 技能 / MCP 市场」窗口的搜索结果/精选卡片上点【一键安装】,带实时进度条。
底层执行的是 `dsh plugin --profile web add <包>`,需要 `dsh` 在 PATH;安装成功后自动记入「管理」页。

---

## 三、MCP 服务器接入

MCP 属于 DSH 的服务端能力。客户端**不提供一键部署**,只负责打开其 **GitHub 仓库**页面
(点卡片上的【打开 GitHub 仓库】),请按仓库说明自行运行/接入;
也可在 `config/plugins.json` 的 `mcpServers` 里登记便于统一管理。

---

## 四、注意

- 客户端**默认不修改 DSH 服务本身**,只通过 `dsh plugin add` / MCP 配置与补丁来"兼容更多插件"。
- 想"内置很全" → 在 `config/plugins.json` 里增加更多项 + 用 `install-plugins.ps1` 批量装进去。
- 补丁(patches)由客户端启动时自动拉起,无需安装,也不占用 `dsh plugin`。
